# Data Analysis with Pandas: Movies & Shows

## Project Overview

This project uses Python and pandas to clean, organize, and analyze a dataset containing information about movies and shows.

## Objectives

- Load and inspect the dataset
- Examine the structure and data types
- Identify data-quality issues
- Clean inconsistent data
- Manipulate DataFrames
- Filter and analyze records
- Prepare the dataset for further analysis

## Technologies & Libraries

- Python
- Pandas
- Jupyter Notebook

## Analysis

The project focuses on practical pandas techniques including:

- DataFrame inspection
- Data cleaning
- Indexing
- Filtering
- Data manipulation
- Identifying and correcting data-quality issues
